Which APIs work?

Use the full HTTPS chat completions URL from each provider. Both APIs must accept bearer keys and the chat completions format, and allow browser requests (CORS). Native messages or generate-content endpoints need an adapter.

You can also use OpenRouter for either player: https://openrouter.ai/api/v1/chat/completions, with an exact ID from its model catalog.

Each key is sent only to that player’s API URL and stays in this tab’s memory. API usage is billed by each provider.
